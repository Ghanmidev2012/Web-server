# Web server exemple

This your own server for you without using any tool

# How it work

* first install `Go` 
* Extarte file
* and you find file name `server.exe` or run `go run main.go`

# how to use
 When you open file or write `go run main.go`
 Write `http://localhost:8080/` `http://localhost:8080/form.html`
